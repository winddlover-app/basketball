# Basketball Training Camp APP PRD

This repository contains product requirement documents and generation scripts for a basketball training camp app.

## Contents

- `build_prd.py`: Generates the Chinese PRD document.
- `build_prd_en.py`: Generates the English PRD document.

## Product Scope

The app is designed for basketball training organizations, coaches, students, and parents. It covers course enrollment, schedules, class attendance, after-class training tasks, training video submission, AI-assisted analysis, coach review, feedback reports, and growth records.
